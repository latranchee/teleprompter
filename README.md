# Teleprompter

Multi-room web teleprompter. Python + aiohttp. Each path is its own isolated room — `/my-show` and `/another-show` share no state. Visiting `/` redirects to a fresh SFW slug generated by `mkname --sfw` (e.g. `/the_slurping_axolotl`).

Live instance: **https://teleprompter.bunkers.studio**

## What it does

- Scrolling teleprompter display in any browser
- Phone remote at `/{slug}/remote` (QR code shown when no text loaded)
- Live state sync across all clients in a room via SSE
- Per-room: text, font size, scroll speed, margins, play/pause, scroll position

## Requirements

- Python 3.11+
- `aiohttp`
- `mkname` binary on `$PATH` — used to generate room slugs. Build from https://github.com/latranchee/funny_password_generator and place the binary somewhere in `$PATH` (or alongside `server.py`).

## Run

```bash
pip install aiohttp
python3 server.py
```

Listens on `0.0.0.0:8090`. Open `http://localhost:8090/` — you'll be redirected to a fresh slug.

## Routes

All API calls are scoped under `/{slug}/`:

| Route | Method | Purpose |
|-------|--------|---------|
| `/` | GET | 302 to a fresh `mkname --sfw` slug |
| `/healthz` | GET | Liveness probe |
| `/lib/*` | GET | Static assets (pedal.svg) |
| `/{slug}` | GET | Teleprompter display (creates the room if absent) |
| `/{slug}/remote` | GET | Phone remote control UI |
| `/{slug}/events` | GET | SSE stream for that room |
| `/{slug}/status` | GET | Room state JSON |
| `/{slug}/sample` | GET | Sample script text |
| `/{slug}/text` | POST / DELETE | Set or clear teleprompter text (HTML sanitized) |
| `/{slug}/control` | POST | `play`, `pause`, `reset`, `scroll`, `sync`, `pedal` |
| `/{slug}/settings` | POST | Update font size, speed, margins, etc. |

Slug regex: `^[a-z0-9][a-z0-9_-]{0,63}$` (anything else → 404).

## Keyboard shortcuts (main display)

| Key | Action |
|-----|--------|
| `Space` | Play / pause |
| `Up` / `Down` | Scroll position |
| `Left` / `Right` | Adjust speed |
| `+` / `-` | Adjust font size |
| `Home` | Reset to top |
| `F` | Fullscreen |

Mouse wheel also scrolls.

## Deploy (supervisor)

`teleprompter.supervisor.conf` is a working supervisor program file. Copy `server.py`, `www/`, `lib/`, and `sample.txt` to `/opt/teleprompter/`, place the `mkname` binary on `$PATH`, then drop the supervisor file into `/etc/supervisor/conf.d/` and `supervisorctl reload`.

## Notes

- **Slugs are not secrets.** `mkname --sfw` outputs roughly 100k combinations — anyone who knows or guesses the slug joins the room. Fine for demos; if you need privacy, append random hex.
- **Rooms are ephemeral.** All state is in process memory. Restart drops everything. Idle rooms (no SSE clients) are garbage-collected after 1 hour.
- **SSE keepalives.** The server emits `: ping` every 15s and sets `X-Accel-Buffering: no` so proxies (Cloudflare, nginx) don't buffer the stream.
